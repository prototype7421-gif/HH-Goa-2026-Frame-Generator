
# HH Goa 2026 - Frame & ID Card Generator

A client-side web application built for the HH Goa 2026 Shortlisting Task. 

## Overview
- **Formats:** Supports Format A (PFP overlay) and Format B (Builder ID Badge).
- **Compliance:** Integrates the mandatory `#FrameInGoa` hashtag feature[cite: 1].
- **Stack:** HTML5 Canvas, Tailwind CSS, Vanilla JavaScript.
